# Kinbo 隐私与法律合规文档

## 1. 隐私保护策略

### 1.1 数据收集

**✓ 无用户数据收集**
- **不收集个人信息**：不收集用户的姓名、邮箱、电话等个人标识信息
- **不收集输入内容**：不记录或存储任何键盘输入的具体内容
- **不收集使用数据**：不统计用户的使用频率、时长或偏好
- **不收集设备信息**：不收集设备型号、系统版本、硬件信息等
- **不收集位置信息**：不访问或存储用户的地理位置数据
- **不收集行为数据**：不跟踪用户的应用使用行为或浏览历史

### 1.2 数据存储

**✓ 本地存储**
- **仅存储应用设置**：
  - 当前选择的音效配置
  - 键盘和鼠标音量设置
  - 开机自启状态
- **存储方式**：使用 macOS 标准偏好设置存储机制（NSUserDefaults）
- **无云端同步**：所有设置仅存储在本地设备，不进行任何云端同步或备份
- **数据清除**：应用卸载后，所有设置数据自动清除

### 1.3 权限使用

| 权限 | 用途 | 必要性 | 处理方式 |
|------|------|--------|----------|
| **辅助功能权限** | 监听全局键盘和鼠标事件以触发音效 | 必需 | 首次启动时请求，通过系统弹窗引导用户前往系统设置开启 |
| **音频播放权限** | 播放音效反馈 | 隐式授权 | 系统自动授予，无需用户手动开启 |

### 1.4 安全措施

- **事件处理**：仅处理事件类型和键码，不解析具体字符或按键内容
- **内存管理**：音频文件预加载后，不保留原始文件路径
- **权限检查**：定期验证辅助功能权限状态，确保功能正常运行
- **事件传递**：事件监听后完整传递，不拦截或修改系统事件
- **最小权限原则**：仅请求必要的辅助功能权限，不请求其他不必要的系统权限
- **代码签名**：应用经过代码签名，确保安全性和完整性

## 2. 法律合规分析

### 2.1 隐私法规合规性

| 法规 | 合规状态 | 说明 |
|------|----------|------|
| **GDPR (欧盟通用数据保护条例)** | ✅ 合规 | 不收集个人数据，无需用户同意，符合数据最小化原则 |
| **CCPA/CPRA (加州消费者隐私法案)** | ✅ 合规 | 不收集个人信息，无数据销售，符合透明度要求 |
| **LGPD (巴西通用数据保护法)** | ✅ 合规 | 不收集个人数据，符合数据保护原则 |
| **PIPL (中华人民共和国个人信息保护法)** | ✅ 合规 | 不收集个人信息，数据存储本地化，符合相关要求 |
| **Apple App Store Review Guidelines** | ✅ 合规 | 遵循权限使用规范，不收集用户数据，符合 App Store 审核要求 |

### 2.2 潜在法律风险

#### 2.2.1 权限相关风险
- **辅助功能权限**：
  - **风险**：用户可能对全局事件监听产生隐私担忧，误认为应用会记录键盘输入
  - **缓解措施**：
    - 明确告知权限用途，仅用于触发音效
    - 仅监听事件类型和键码，不记录具体内容
    - 在权限请求时提供清晰的说明
    - 代码实现中确保不存储任何输入内容
  - **合规依据**：符合 macOS 辅助功能权限使用规范，用于提高应用可用性

#### 2.2.2 音频版权风险
- **音频样本**：
  - **风险**：如果使用第三方音频样本，可能涉及版权问题
  - **缓解措施**：
    - 使用原创音频或获得授权的样本
    - 部分配置包含 LICENSE 文件，确保合法使用
    - 定期审查音频样本的版权状态
  - **合规依据**：确保所有音频样本具有合法使用权限

#### 2.2.3 系统兼容性风险
- **事件监听**：
  - **风险**：macOS 版本更新可能影响 CGEventTapCreate 行为，导致功能异常
  - **缓解措施**：
    - 定期测试不同 macOS 版本的兼容性
    - 及时更新适配新系统版本
    - 提供版本兼容性说明
  - **合规依据**：遵循 Apple 开发者指南，使用官方推荐的 API

#### 2.2.4 责任风险
- **用户体验**：
  - **风险**：用户可能因音效音量过大或持续播放导致听觉不适
  - **缓解措施**：
    - 提供音量调节功能
    - 默认音量设置适中
    - 在应用说明中提示合理使用
  - **合规依据**：提供用户控制选项，避免强制播放高音量

### 2.3 免责声明
- 应用仅用于增强用户体验，不保证完全模拟真实键盘音效
- 辅助功能权限仅用于事件监听，不用于其他目的
- 如遇系统权限变更导致功能异常，需重新授权
- 应用不负责因音频播放产生的任何听觉问题
- 应用不保证在所有 macOS 版本上的完全兼容性
- 应用不对用户使用过程中产生的任何直接或间接损失负责

## 4. 隐私政策摘要

### 4.1 核心原则
- **无数据收集**：Kinbo 不收集任何用户个人数据或使用数据
- **本地存储**：仅存储应用设置，无云端同步
- **最小权限**：仅使用必要的辅助功能权限
- **透明操作**：明确告知权限用途，不进行任何隐蔽操作

### 4.2 用户权利
- **知情权**：用户有权了解应用的权限使用和数据处理情况
- **控制权**：用户可以随时在系统设置中管理辅助功能权限
- **删除权**：应用卸载后，所有设置数据自动清除

### 4.3 隐私保护承诺
- 尊重用户隐私，不收集任何个人信息
- 仅使用必要的系统权限，不请求额外权限
- 透明告知权限用途，避免用户误解
- 持续改进隐私保护措施，适应新的隐私法规要求

## 5. 技术实现细节

### 5.1 事件监听实现
- 使用 `CGEventTapCreate` 创建全局事件监听
- 仅监听事件类型和键码，不解析具体字符
- 事件处理后完整传递，不拦截系统事件
- 忽略按键重复事件，避免连续触发音效

### 5.2 权限请求流程
- 首次启动时尝试创建事件监听，触发系统权限提示
- 检查权限状态，如未授权则显示自定义提示
- 引导用户前往系统设置开启辅助功能权限
- 提供清晰的权限用途说明

### 5.3 数据存储实现
- 使用 `UserDefaults` 存储应用设置
- 存储的键值对包括：
  - 当前音效配置
  - 键盘音量
  - 鼠标音量
  - 开机自启状态
- 无其他数据存储或缓存
