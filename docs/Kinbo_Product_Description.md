# Kinbo 产品功能描述

## 产品概述

Kinbo 是一款为 macOS 用户打造的键盘音效增强工具，通过模拟不同风格的机械键盘音效，为日常打字和鼠标操作带来沉浸式的听觉反馈体验。

- **轻量设计**：以菜单栏应用形式运行，无 Dock 图标，不占用系统资源
- **实时反馈**：每次按键和鼠标点击都能获得即时的音效反馈
- **个性化定制**：提供多种音效配置，满足不同用户的听觉偏好

## 核心功能

### 1. 键盘音效模拟
- **多种风格选择**：内置 17 种经典键盘音效配置，包括 Keychron、Typewriter、机械轴等风格
- **分层音效**：每个按键触发多层次声音（敲击、主体、共振、回弹），还原真实键盘手感
- **智能随机化**：音量、音高、延迟的细微变化，避免音效单调重复

### 2. 鼠标点击音效
- **左右键区分**：左键和右键点击提供不同的音效反馈
- **独立音量控制**：可单独调节鼠标音效音量，适应不同使用场景

### 3. 个性化设置
- **音量调节**：键盘和鼠标音量独立控制，支持 0-100% 精细调节
- **一键切换**：从菜单栏快速切换不同音效配置，即时预览效果
- **开机自启**：支持设置为开机启动，无需每次手动打开

## 用户体验

### 安装与设置
- **极简安装**：拖拽安装，无需复杂配置
- **权限引导**：首次启动自动检测并引导用户开启必要权限
- **直观界面**：菜单栏图标点击即可展开所有控制选项

### 日常使用
- **无感知运行**：后台静默运行，不干扰其他应用
- **即时反馈**：按键按下瞬间即可听到音效，延迟极低
- **场景适配**：从安静办公到家庭使用，通过音量调节适应不同环境

### 音效体验
- **真实感**：多层次音效叠加，模拟真实机械键盘的敲击感
- **多样性**：17 种预设音效，满足不同用户的审美偏好
- **沉浸感**：打字时的音效反馈增强专注力和愉悦感
